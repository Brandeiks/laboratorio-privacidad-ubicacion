LAB-01 // privacidad

Qué ubicación puede revelar una visita web

Compara lo que un sitio estima por tu IP con lo que obtiene cuando tú aceptas compartir la ubicación del navegador.

Esta página no está en un contexto seguro (HTTPS o localhost). El navegador bloqueará la geolocalización.

01 Antes de empezar

  • Qué se pide: una estimación de ubicación por tu IP y, si lo autorizas, la ubicación de tu navegador (latitud, longitud y margen de precisión).
  • Para qué: comparar ambos métodos y medir su diferencia. Nada más.
  • Dónde se guarda: solo en este navegador, y solo si pulsas «Guardar». No hay servidor que reciba tus coordenadas.
  • Cómo se borra: con el botón «Borrar todo» del paso 05.
  • Puedes rechazar: en cualquier momento. Rechazar el permiso también es un resultado válido.

02 Estimación por IP

Cualquier servidor que visitas ve tu IP pública. Con bases de datos GeoIP se puede estimar país, región o ciudad, sin pedirte permiso.

Al pulsar, tu navegador consulta un servicio externo (ipapi.co, o ipwho.is si falla). Ese servicio recibe tu IP.

03 Ubicación del navegador

Usa la API navigator.geolocation. El navegador te mostrará su propio aviso: si no aceptas, la página no recibe coordenadas.
